# Telugu Songs Download Web App

This is a simple Flask web application for sharing and downloading Telugu songs that are copyright-free.

## Features
- List all songs in the `static/audio/` folder
- Play songs in the browser
- Download songs for free

## How to Use
1. Place your copyright-free Telugu song files (MP3, WAV, OGG) in the `static/audio/` folder.
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the app:
   ```
   python app.py
   ```
4. Open your browser and go to `http://127.0.0.1:5000/`

## Licensing
- Only upload and share songs that are in the public domain or have a license allowing free distribution.
- Clearly mention the license/source for each song if possible.
